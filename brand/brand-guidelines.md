# Tawilati — Official Brand Identity & UI Design Guidelines

## 1. Project Overview

**Brand Name:** Tawilati  
**Brand Display Name:** `tawilati.`  
**Product Type:** Multi-tenant restaurant management and QR ordering SaaS  
**Tagline:** Good food, smoother service.

Tawilati is a restaurant technology platform that connects customers, restaurant owners, kitchen staff, and waiters through a seamless digital ordering experience.

The platform allows customers to scan a QR code at their table, browse the menu, place orders, and follow their dining experience, while restaurant teams manage menus, orders, tables, kitchen operations, and payments.

Our brand should communicate:

- Elegance and simplicity
- Modern restaurant hospitality
- Trust and professionalism
- Seamless connection between customers and restaurants
- Technology that feels natural and approachable

**Important:** Tawilati must NOT look like a generic AI startup, futuristic technology platform, or traditional restaurant website.

We want an elegant, timeless, premium identity that balances hospitality with modern software.

## 2. Official Logo — Cup + Wi-Fi

### Logo Concept

The approved Tawilati logo combines two meaningful elements:

**Coffee Cup**
- Represents hospitality, restaurants, cafés, and the dining experience.
- Uses an elegant, minimalist outline.
- Should have smooth curves and balanced proportions.
- Includes a subtle saucer line beneath the cup.

**Wi-Fi Signal**
- Positioned above the coffee cup.
- Represents digital connectivity, QR ordering, and technology.
- Uses three curved signal elements.
- Appears in warm amber to contrast with the forest-green cup.

Together, these elements represent the connection between hospitality and technology.

### Logo Typography

The brand name is written as:

**tawilati.**

Typography requirements:
- Elegant, high-contrast serif typography.
- Inspired by Playfair Display.
- Refined curves and professional letter spacing.
- All lowercase.
- Forest green lettering.
- Small amber period at the end.

Use **Playfair Display** as the initial implementation font for the wordmark, with the understanding that the final logo may require customized vector lettering.

### Approved Logo Variations

**Primary horizontal logo**
- Cup + Wi-Fi symbol on the left.
- `tawilati.` wordmark on the right.
- Optional tagline underneath.
- Preferred for landing pages and desktop navigation.

**Stacked logo**
- Cup + Wi-Fi symbol centered above the wordmark.
- Optional tagline underneath.
- Used for QR table cards, printed materials, and promotional assets.

**Icon-only logo**
- Cup + Wi-Fi symbol without text.
- Used for favicon, mobile app icon, and compact navigation.

**Reverse logo**
- Cream-colored cup and lettering.
- Amber Wi-Fi signal.
- Forest-green background.

### Logo Usage Rules

- Preserve the approved logo proportions.
- Maintain clear spacing around the symbol and wordmark.
- Never stretch, rotate, distort, or add shadows to the logo.
- Do not replace the cup with utensils, a plate, a robot, or generic AI symbols.
- Do not use gradients or 3D effects.
- Avoid excessive decoration.
- Use vector SVG assets for production.
- Ensure the icon remains recognizable at small sizes.

The approved brand reference image is the source of truth for the logo's appearance. Recreate it accurately rather than inventing a different cup or Wi-Fi symbol.

## 3. Official Color Palette

These five colors are the approved Tawilati brand palette.

| Color | Hex | Purpose |
|---|---|---|
| Forest Green | `#254D3B` | Primary brand color |
| Sage | `#8BA88B` | Secondary brand color |
| Cream | `#F8F5EC` | Main background color |
| Amber | `#E5A45B` | Brand accent color |
| Charcoal | `#202B26` | Primary text color |

### Forest Green — #254D3B

Use for:
- Primary buttons
- Navigation and sidebar
- Active navigation items
- Important headings
- Brand elements
- Selected filters and tabs
- Key interface actions

### Sage — #8BA88B

Use for:
- Secondary visual accents
- Subtle backgrounds
- Selected cards
- Secondary buttons
- Decorative details
- Soft interface highlights

Do not use sage as the only indicator of success or status.

### Cream — #F8F5EC

Use for:
- Main application backgrounds
- Landing page backgrounds
- Customer ordering screens
- Large content sections
- Soft background surfaces

Use white or near-white cards when needed to establish hierarchy.

### Amber — #E5A45B

Use sparingly for:
- Wi-Fi signal in the logo
- Wordmark period
- Important highlights
- Selected decorative accents
- Special promotional elements

Amber should not replace forest green as the primary CTA color.

### Charcoal — #202B26

Use for:
- Body text
- Dashboard content
- Form labels
- Tables
- Headings
- Navigation text on light backgrounds

### Color Distribution

Recommended visual balance:

- 60% cream and light neutral surfaces
- 25% forest green and charcoal
- 10% sage
- 5% amber accents

These percentages are visual guidelines, not strict implementation requirements.

## 4. Typography System

### Brand Typography — Playfair Display

Use for:
- Tawilati wordmark reference
- Landing page hero headings
- Marketing section titles
- Elegant promotional headlines

The font should create a sophisticated restaurant-inspired identity.

### Application Typography — Inter

Use for:
- Dashboard headings
- Navigation
- Buttons
- Forms
- Tables
- Menu item descriptions
- Prices
- Kitchen order tickets
- Waiter screens
- Notifications

Inter should remain the primary application font because it is highly readable in operational interfaces.

### Typography Rules

- Avoid excessive font weights.
- Use clear visual hierarchy.
- Keep line heights comfortable.
- Avoid uppercase paragraphs.
- Use uppercase only for small labels or intentional decorative text.
- Ensure prices, order numbers, and table numbers are immediately readable.
- Prioritize operational readability over decorative typography.

## 5. Design System

### Overall UI Style

Tawilati should use:

- Elegant minimalist layouts
- Generous whitespace
- Warm cream backgrounds
- Forest-green primary actions
- White and subtle neutral cards
- Soft rounded corners
- Light borders
- Subtle shadows
- Consistent spacing
- Clean line icons
- Smooth but restrained transitions

Avoid:
- Glassmorphism
- Neon colors
- Excessive gradients
- Glowing buttons
- AI-style illustrations
- Heavy shadows
- Overly futuristic interfaces
- Excessive animations
- Cluttered dashboards

### Component Styling

**Primary buttons**
- Forest-green background.
- Cream or white text.
- Medium rounded corners.
- Clear hover, focus, loading, and disabled states.

**Secondary buttons**
- Light neutral or sage-tinted background.
- Forest-green text.
- Subtle border when appropriate.

**Cards**
- White or near-white background.
- Subtle border.
- Medium rounded corners.
- Minimal shadow.
- Consistent padding.

**Inputs**
- Light background.
- Clear charcoal labels.
- Forest-green focus indicator.
- Accessible validation messages.

**Navigation**
- Clean, organized, and minimal.
- Forest green for active states.
- Consistent line icons.
- Strong hierarchy between navigation sections.

**Status badges**
- Distinct semantic colors for order states.
- Always include readable text labels.
- Do not rely exclusively on brand colors to represent operational status.

**Tables**
- Clear column alignment.
- Subtle separators.
- Readable numeric values.
- Appropriate empty, loading, and error states.

### Responsive Design

- Mobile-first for customer ordering.
- Desktop-first but responsive for restaurant management.
- Tablet-friendly kitchen and waiter screens.
- Large enough touch targets for operational use.
- No unnecessary horizontal scrolling on mobile.

## 6. Platform-Specific Design Guidelines

### A. Public Landing Page

Goal: Present Tawilati as a premium yet approachable restaurant technology platform.

Design requirements:
- Cream background.
- Horizontal Tawilati logo.
- Elegant serif hero heading.
- Clear explanation of QR ordering and restaurant operations.
- Forest-green CTA buttons.
- High-quality restaurant imagery.
- Realistic product interface previews.
- Spacious sections.
- Minimal decorative elements.

Suggested hero headline:

**A smoother way to serve.**

Supporting copy:

**From the first scan to the final bill, Tawilati brings your restaurant's ordering and operations together.**

### B. Restaurant Owner Dashboard

Goal: Help owners manage their business efficiently.

Design requirements:
- Professional SaaS layout.
- Compact Tawilati logo in the sidebar.
- Organized navigation.
- Clear operational overview.
- Simple metric cards.
- Readable tables and forms.
- Efficient category, menu, staff, and table management.
- Forest-green actions.
- Cream or light-neutral page backgrounds.

The dashboard should feel professional and operational, not like a decorative restaurant website.

### C. Customer QR Ordering Interface

Goal: Deliver a beautiful, intuitive dining experience.

Design requirements:
- Mobile-first.
- Elegant restaurant-inspired appearance.
- Cream background.
- Forest-green navigation and actions.
- Clear menu categories.
- High-quality food photography.
- Readable item descriptions and prices.
- Simple add-to-cart interaction.
- Clear order submission flow.
- Easy access to the running bill.
- Visible table identification.

The customer should be able to understand and use the interface without instructions.

### D. Kitchen Dashboard

Goal: Support fast and accurate order preparation.

Design requirements:
- Prioritize readability and efficiency.
- Clearly display new orders.
- Show table number, order items, quantities, notes, and status.
- Use distinct status indicators.
- Provide large, accessible action buttons.
- Avoid decorative elements that distract staff.
- Support responsive layouts for tablets.

Brand styling must never compromise operational clarity.

### E. Waiter Dashboard

Goal: Make table service and bill management simple.

Design requirements:
- Clear table overview.
- Easy identification of table and order status.
- Quick access to active orders.
- Readable bill summaries.
- Efficient payment recording workflow.
- Large touch-friendly controls.
- Consistent styling with the owner and kitchen dashboards.

## 9. Brand Voice

Tawilati communicates in a way that is:

- Clear
- Friendly
- Professional
- Confident
- Helpful
- Simple

Avoid unnecessarily technical marketing language.

Examples:

Instead of: "Advanced AI-powered restaurant digitization ecosystem"

Use: "Everything your restaurant needs to serve more smoothly."

Instead of: "Initiate digital menu interaction"

Use: "Scan to view the menu."

Instead of: "Transaction completed successfully"

Use: "Payment recorded successfully."

## 10. Implementation Requirements for Claude

Apply the approved Tawilati identity consistently throughout the existing codebase.

### Step 1 — Audit the Current UI

Review:
- Existing colors
- Fonts
- Logo usage
- Buttons
- Cards
- Forms
- Navigation
- Tables
- Responsive layouts
- Customer ordering screens
- Kitchen and waiter interfaces

Identify inconsistencies with the new brand guidelines.

### Step 2 — Centralize Brand Tokens

Create or update the application's centralized design tokens.

Suggested CSS variables:

```css
:root {
  --brand-primary: #254D3B;
  --brand-secondary: #8BA88B;
  --brand-background: #F8F5EC;
  --brand-accent: #E5A45B;
  --brand-text: #202B26;

  --surface-primary: #FFFFFF;
  --surface-secondary: #F8F5EC;

  --font-brand: "Playfair Display", Georgia, serif;
  --font-ui: "Inter", Arial, sans-serif;
}
```

Extend these tokens with accessible text, border, focus, hover, disabled, error, warning, and success colors as needed.

### Step 3 — Implement the Logo System

Create reusable logo assets/components for:
- Primary horizontal logo
- Stacked logo
- Icon-only logo
- Light background variation
- Dark background variation
- Favicon

Prefer production-ready SVGs.

Do not use an emoji, generic coffee icon, or generic Wi-Fi icon as a substitute for the approved logo.

### Step 4 — Apply the Design System

Update shared UI components first, then apply them consistently across the application.

Preserve:
- Existing functionality
- API integrations
- Authentication
- Permissions
- Navigation behavior
- Business logic
- Data handling

This is a branding and UI consistency task, not a request to redesign backend architecture.

### Step 5 — Validate

Verify:
- Visual consistency across screens
- Correct font loading
- Color contrast and accessibility
- Mobile responsiveness
- Touch usability
- Logo readability at small sizes
- Hover and focus states
- Loading and error states
- No broken functionality
- No unnecessary duplicated styles

### Step 6 — Report Changes

Provide:
1. Files modified.
2. Brand tokens introduced.
3. Logo assets/components created.
4. Pages updated.
5. Responsive and accessibility improvements.
6. Any remaining inconsistencies.
