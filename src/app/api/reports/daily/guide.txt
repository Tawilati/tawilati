However, your frontend can call it twice (once for each day) and display them side-by-side, or the owner can navigate between dates.

Here is how the report handles dates and what your options are:

🎯 How the Daily Report Works
Endpoint	What it returns
GET /api/reports/daily?date=2026-11-04	Report for Nov 4 only
GET /api/reports/daily?date=2026-11-03	Report for Nov 3 only
Each call returns exactly one day. The backend does not aggregate multiple days.

🚨 Why It Works This Way
The owner usually wants one day at a time. They open the report in the morning and check yesterday's sales. They don't need a two-day view.

Performance: Querying one day is faster than querying multiple days.

Flexibility: The frontend can call the endpoint for any date (last week, last month, etc.) without the backend changing.

✅ How the Frontend Shows "Today and Yesterday"
The frontend makes two separate calls:

typescript
// Frontend: Dashboard
const today = new Date().toISOString().split("T")[0];
const yesterday = new Date(Date.now() - 86400000).toISOString().split("T")[0];

const [todayReport, yesterdayReport] = await Promise.all([
  fetch(`/api/reports/daily?date=${today}`).then(r => r.json()),
  fetch(`/api/reports/daily?date=${yesterday}`).then(r => r.json()),
]);
Then the UI shows:

🎯 What About a "Weekly" or "Monthly" Report?
If the owner wants a range (e.g., "last 7 days"), you have two options:

Option A: Frontend loops
The frontend calls GET /api/reports/daily 7 times (once per day) and aggregates the results.

typescript
const days = ["2026-10-29", "2026-10-30", ..., "2026-11-04"];
const reports = await Promise.all(days.map(d => fetch(`/api/reports/daily?date=${d}`).then(r => r.json())));
Option B: Backend adds a range endpoint
You build GET /api/reports/range?start=2026-10-29&end=2026-11-04 that queries the Payment table for the entire range in one query.

This is a future feature, not required for Checkpoint 2.
