🛠️ What Changes in the Code
1. Schema: Add status to GuestSession (as described earlier).

2. POST /api/guest-sessions: The session is created with status: "PENDING" (default).

3. OrderService.createOrder: Add a check after finding the guest:

typescript
// Step 1: After findByToken
if (guest.status !== "ACTIVE") {
  throw new HttpException(403, "guest_session_pending_approval");
}
4. New endpoint: GET /api/guest-sessions/me (public, uses the token) — returns the session status so the frontend can poll:

typescript
// GET /api/guest-sessions/me
export async function GET(request: NextRequest) {
  const token = getGuestTokenFromRequest(request);
  if (!token) throw new AuthenticationException("unauthorized");
  
  const guest = await guestSessionRepo.FindByToken(token);
  if (!guest) throw new NotFoundException("guest_not_found");
  
  return NextResponse.json({
    success: true,
    data: { status: guest.status, sessionId: guest.sessionId },
  });
}
5. Waiter endpoints:

GET /api/waiter/pending-guests — lists all PENDING sessions for the business.

PATCH /api/waiter/guest-sessions/:id/confirm — sets status: "ACTIVE".

PATCH /api/waiter/guest-sessions/:id/reject — sets status: "REJECTED" and revokedAt.

6. Frontend (guest):

typescript
async function submitOrder() {
  // 1. Create session (returns PENDING)
  const sessionRes = await fetch("/api/guest-sessions", {
    method: "POST",
    body: JSON.stringify({ qrToken }),
  });
  const { token } = await sessionRes.json();
  localStorage.setItem("guestToken", token);

  // 2. Poll until ACTIVE
  showScreen("Waiting for waiter to confirm...");
  const poller = setInterval(async () => {
    const statusRes = await fetch("/api/guest-sessions/me", {
      headers: { Authorization: `Bearer ${token}` },
    });
    const { data } = await statusRes.json();

    if (data.status === "ACTIVE") {
      clearInterval(poller);
      // 3. Now submit the order
      await fetch("/api/orders", {
        method: "POST",
        headers: {
          Authorization: `Bearer ${token}`,
          "Idempotency-Key": crypto.randomUUID(),
        },
        body: JSON.stringify({ items: cart }),
      });
      showScreen("Order submitted!");
    } else if (data.status === "REJECTED") {
      clearInterval(poller);
      showScreen("Waiter rejected your session. Please ask for help.");
    }
  }, 3000); // poll every 3s
}
